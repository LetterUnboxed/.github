# LetterUnboxed Organization

This is the organization used for management of the LetterUnboxed Project.
The project is currently private as it is in early developement.
# Project Description

## This project is fully organic

No AI was used for code generation in this project.

## Letterboxd is great, but its not perfect

They have some awesome features, the most important being watchlist/history and
a community. However, it is lacking some pretty important features.

### 1. No recommendations

- They have everyones watch history and the ratings they give to movies but
don't use it to recommend movies.

### 2. No API

- Letterboxed has great data on your watch history and watchlist but users are
unable to use it themselves. If someone wanted to have something like Sonarr for
movies, they would have to manually create lists rather than using what already
exists in Letterboxd.

## Goals

### Import data from other sources

- At least be able to import existing watch data from Letterboxd

### Recommendations

- Have an effective recommendation algorithm/model

### API

- Have an API with as much usability as possible for developers and other users
- With AI decreasing the entry level for people to develop their own apps, it is
likely more people would want to use an API.
